# Озвучка, синхронизация, субтитры

## 1. Распознать озвучку

Положи запись в `public/voice.wav` (любой формат конвертируй: `npx remotion ffmpeg -i in.m4a public/voice.wav`). Имя без скобок и пробелов.

```bash
node scripts/transcribe.mts      # → src/reel/voice-captions.json, слова с startMs/endMs
```
Whisper `large-v3-turbo`, по умолчанию `language: "ru"` (для другого языка поменяй в `scripts/transcribe.mts`), локально на GPU (WebGPU), первая загрузка модели ~1,5 ГБ. В Node 23 нет `using` — в скрипте обычные переменные, не меняй.

Выведи слова с таймингами и сравни с текстом пользователя: при записи текст часто чуть меняется — субтитры делай по фактической речи и скажи пользователю, что отличается.

## 2. Синхронизация

**Озвучка есть до сборки** (лучше): размечай удары в блоках сразу секундами слов; `timewarp.json` остаётся тождественным `[[0,0],[120,120]]`.

**Ролик собран до озвучки**: не переписывай блоки — заполни карту `src/reel/timewarp.json`: `anchors: [[старая_секунда_удара, новая_секунда_слова], …]`, ~1–2 точки на фразу, обе колонки строго возрастают. Блоки (`useBlockTime`), длительности (`blockFrom` в `Reel.tsx`) и звук (`mix_sfx.py`) пересчитываются сами. Примечания:
- Первая точка — на первом слове (например `[0.0, 0.1]`): до неё карта держит стартовый кадр; `blockFrom(0)` всегда 0.
- Последняя — `[конец_таймлайна, конец_озвучки]`; `durationInFrames` в `Root.tsx` = round(конец_озвучки × 30). Хвост тишины обрежь.
- Склейку ставь чуть раньше слова, с которого начинается новая сцена (хлыст заканчивается на слове).
- Если в записи на какое-то событие осталось < 0,4 с — упрости сцену (убери элементы) или пусть анимация продолжится под следующей фразой, а склейка уйдёт на ударное слово позже. Не сжимай всё в кашу и не вставляй паузы в запись.

## 3. Субтитры

```bash
python3 scripts/captions_from_whisper.py   # → src/reel/captions.json
```
- `scripts/caption_fixes.json`: `fixes` — исправления распознавания по словам (`нее` → `неё`, `гит` → `git`), `code` — слова, которые показываются моноширинным оранжевым. Исправления, которые затрагивают регистр или знак препинания внутри слова, проще поправить вручную прямо в `captions.json`.
- Экраны режутся автоматически (знак препинания, 4 слова, ~22 символа); проверь список в выводе и поправь `pageBreakAfter` в JSON по смыслу.
- Компонент `Captions`: `TITLE` 50 px на y ≈ 1400, ширина 820, текущее слово — `accent`.

## 4. Включить звук

В `src/reel/Sfx.tsx`: `HAS_VOICE = true`, затем пересведи звуки (`python3 scripts/mix_sfx.py`) — появится сайдчейн под голос. Проверь уровни: RMS эффектов должен быть заметно ниже RMS голоса.
